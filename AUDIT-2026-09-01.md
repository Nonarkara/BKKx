## Defects found under a production-style smoke test

### Optional Worker configuration crashed instead of degrading

`/api/live/cctv`, `/api/live/fires`, and `/api/live/longdo/*` dereferenced the
Worker environment before checking whether it existed. Vinext's production
server can call the Worker with no environment object, producing HTTP 500.

Fix: optional bindings now use optional access. Regression tests call the
built Worker with `env === undefined` and require a valid, source-labelled
response envelope.

### BMA's former open rain route is no longer open

The agency endpoint returns HTTP 200 but its JSON body is an authentication
error: `username หรือ Password ไม่ถูกต้อง`. Treating status 200 as a reading
would be a serious data-quality failure.

Fix: the adapter detects the credential error, shows no rainfall number, and
states why. The source ledger now classifies the endpoint as credentialed and
researched—not keyless and wired. A separate official Bangkok Open Data source
records the public flood-risk and annual road-flood datasets as historical
context, explicitly not live observation.

### One upstream failure hid a valid second feed

Forecast and air quality come from separate Open-Meteo services. A forecast
rate limit previously discarded valid CAMS air-quality readings.

Fix: each component now carries availability and observation time separately.
If either succeeds, its real values remain visible while unavailable fields
stay blank and the partial failure is printed beside them.

## Release gate

The release is acceptable only when all of these hold on the promoted tree:

- generated GeoJSON, hero monuments, evidence tally and dataset manifest are
  byte-reproducible;
- production build succeeds;
- TypeScript and lint succeed;
- all route and data-integrity tests pass;
- `/api/live/*` returns an envelope rather than a runtime exception when
  optional credentials are absent;
- live deployment serves the key public routes and truthful degraded states.

This document records evidence and corrections, not a promise that every
catalogued source is live. `wired`, `ready`, and `researched` remain different
states on purpose.
