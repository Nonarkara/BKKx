# MSH Audit — 10 November 2026

## Summary
Full audit of BKKx main (bkk.nonarkara.org) and shophouses branch (shophouses.nonarkara.org) for horizontal overflow (MSH: Spatial Hallucination).

## Methodology
- Viewport: 1000×700px (browser default) and 390×844px (iframe probe)
- Measured `scrollWidth` vs `clientWidth` per page
- Flagged elements with `right > viewportWidth + 1`
- Verified fixes by injecting CSS and re-measuring
